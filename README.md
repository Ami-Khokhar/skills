# Skills

[Intentivals](skills/intent-to-evals/SKILL.md) helps an agent turn a subjective request into repeatable checks. It uses examples to clarify what the user wants, tests whether the checks recognize that preference, and compares revisions against a baseline.

Try it with a request like “Use `$intent-to-evals` to help me figure out what would make this tutorial easier for a first-time user.”
